React is an SPA - single page application   

first of all run npx create-react-app

npm - node package manager
npx - node package executer (takes time to create the app use vite instead) 

if app created using npx then delete the following files under src folder - setupTest.js , reportWebVitals.js , logo.svg , App.test.js (used while testing) , App.css and index.css (if not writing css) as they are not needed and also remove the imports of the files which we have just deleted as they are no longer needed in the app.js and index.js and remove uneccesary statements under return and unnessary comments

npm create vite@latest also run npm install if node modules are not present (npm run dev to run the app)

if app created using vite then delete the following files under src folder - assets folder , App.css , index.css and also remove the imports from app.jsx and main.jsx and remove uneccesary statements under return and unnessary comments

npm run start - to start the app on localhost using create-react-app
npm run dev - to start the app using vite

conventions - 

1. name all the functions and their file starting from capital letter 
2. JS files which return HTML should be named by .jsx extension
